# Mathematica---Tabelo-nedolo-enih-integralov

Projektna naloga pri predmetu **Računalniška orodja v matematiki**

## Opis projekta
S pomočjo programa **Wolfram Mathematica** sem sestavila in oblikovala pregledno tabelo standardnih in elementarnih nedoločenih integralov z ustreznimi pogoji ter jo izvozila v format PDF.

## Vsebina repozitorija
- `e6f52f8b-32f7-4d2b-9df8-e490ff50999c (1).nb`: Izvorna koda v programu Mathematica.
- `Tabela_nedoločenih_Integralov.pdf`: Izvožena tabela in kod v PDF formatu.
- `razlaga_kode.m4a`: Zvočna razlaga kode in projekta.
